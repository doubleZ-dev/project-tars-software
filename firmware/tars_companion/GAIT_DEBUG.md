## 默认平滑与转向A/B/C（0.15.8-turnsmooth）

- 前进默认第3/4阶段：`[5,45,45,5]` / `[5,-30,-30,5]`；其余阶段不变。
- 左右转第2/3阶段中间轴统一−30°，第4/5阶段+20°；左侧摆幅40°、右侧45°保持不对称。
- 网页默认前进第4阶段平滑、转向A（第4阶段）；B平滑第3/4/5阶段，C平滑第2～6阶段。正式动作同样默认第4阶段平滑。
- 共用60/180/60ms梯形速度积分，浮点内部计算、最终整数角度；每20ms写目标，300ms精确写终点，零点只转换一次。软件无实际到位反馈。
- 转向可单独勾选第4阶段后额外保持60ms，默认关闭。完整周期1.8秒或1.86秒；不压缩轨迹时间。正式转向无额外保持。
- 平滑转向时第3/5阶段中间轴固定、第4阶段两侧固定；草稿破坏支撑顺序会明确拒绝。直接轨迹仍允许每格±45°自由编辑。
- 角度表、轨迹及等待选项随实验记录保存；改参数无需再次烧录。按A→B依次由用户实测，不自动执行动作。
- 本轮仅3项针对性Mock/参数/轨迹数学及报文长度检查、编译和烧录后只读核对；未跑完整回归，未验证舵机真实跟随、接地或欠压改善。
- 安装证据：固件 `evidence/turnsmooth-image.json`、`evidence/turnsmooth-install.json`，PC `evidence/turnsmooth-install-probe.json`。

## 左右转扩展（候选0.15.5-turnlab，未烧录）

网页增加“测试步态”：前进、向左转、向右转。切换只读取对应方案，不使能、不移动。
角度表、追加阶段边界、执行命令和诊断记录都绑定所选步态；不同步态草稿切换时分别保留。
执行中禁止切换；更换步态会清除安全确认。原来的机械零点、300ms/阶段、末阶段关闭输出、独立回零和急停逻辑不变。

左右转采用已有原始角度表，没有擅自优化：

```text
左转：[0,0,0,0] → [0,-45,-45,0] → [40,-45,-45,-40]
   → [40,20,20,-40] → [0,20,20,0] → [0,0,0,0]
右转：[0,0,0,0] → [0,-45,-45,0] → [-45,-45,-45,45]
   → [-45,20,20,45] → [0,20,20,0] → [0,0,0,0]
```

前6阶段仍只允许缩小各阶段原幅度。新增阶段1/4号边界按动作区分：前进0..10/0..10；
左转0..40/−40..0；右转−45..0/0..45。新增阶段2/3号仍为−45..45；再核对机械物理限位。
只有升级0.15.5-turnlab后才能进行左右转阶段实测；旧0.15.3/0.15.4仍可调试前进，页面不会把左/右转请求降级成前进。
这版也包含用户已批准的前进第4阶段−30°，但不加入新的插值/平滑。

## 打开与使用

双击本目录 `Start-Gait-Debug.cmd`，会打开本机网页。无AI、无百炼、无需API Key。
关闭命令窗口即停止服务。同一标签页刷新会从sessionStorage保留页面授权；
服务重启后旧授权失效，需用新终端打印的完整地址重新打开。
切出页面会释放网页控制权，回来先点击“获取网页控制权”。TARS重启后需手动重新连接，绝不自动恢复动作。
授权错误会同时显示在连接区，不再只藏在页面底部。2026-11-07已修复刷新导致令牌丢失问题；仅电脑页面更新，无需重新烧录。
未连接时设备列表每2秒自动刷新，按USB序列号保留选择；设备消失时禁用连接按钮。
设备重新出现只更新列表，不自动连接、使能或恢复动作。

1. 关闭语音程序、串口监视器和USB日志采集，连接原生USB。
2. 页面点击“获取网页控制权”，选择USB设备并连接。
3. 勾选阶段1、2，只执行这两阶段；勾选第3阶段会自动选择1～3。
4. 按需改角度，例如第3阶段1/4号10°改5°；下方实时显示对应物理输出。
5. 手持/可靠悬空、无遮挡并确认可立即断电，勾选安全确认，点击“使能并执行”。
6. 每阶段300ms，所选末阶段结束后关闭PWM；不补做剩余阶段、不自动回零。
7. 点击独立“回机械零点”按钮，可归零并关闭输出，再继续下一轮。此按钮会驱动四路。

**使能本身会先回机械零位。关闭PWM后不保证维持姿态，不能让机器人无人支撑。**
连接、重连或导入方案不会自动使能；软件急停后需人工清除，清除不会使能。

## 零点与角度

用户已再次确认：机械零点 `[10,0,-10,2]°`，方向 `[+1,-1,+1,-1]`。
页面实际从固件读取，逻辑0°映射为这些值，不再额外叠加一套零点。
“物理输出”只是下发目标，不是舵机反馈或量到的真实角度。

- 原前6阶段只允许缩小各单元格原幅度，零位单元格锁定。
- “追加零位阶段”“复制上一阶段”最多扩展至12阶段。
- 新增阶段：1/4号逻辑0～10°，2/3号−45～45°；另检查换算后的机械硬限位。
- 只允许从阶段1开始连续选择，不允许跳阶段。
- 角度草稿、追加阶段均不覆盖正式步态或机械零点。
- 方案可导出/导入JSON；机械零点/方向/固件基线不匹配时拒绝导入。
