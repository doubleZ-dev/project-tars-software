# TARS 日常语音候选版

2026-11-08。仅修改 Companion，未改动或烧写固件，保留旧语音与三轮测试入口。

## 日常启动

先退出步态调试和其他语音程序，避免争用机器人控制会话和 8765 监听端口。
双击 `Start-Tars-Daily.cmd`。启动时输入控制台**当前剩余免费 token 数**，
至少 100000；API Key 自动从当前 Windows 用户的加密文件加载，不再粘贴。
按回车后等待 READY，即可说话。机器人仍需与电脑处于同一 Wi-Fi。

默认连续对话最多 10 轮、15 分钟。已报告 token 用量达到 20000 后停止下一轮，
用量回执缺失则停止日常模式。该计数不是火山引擎账单硬限额，不能保证错误填写
免费余额时不产生费用。没有自动购买、开通服务或重新注册音色的逻辑。

25 秒没有识别到说话后，麦克风停止上传，屏幕回到 IDLE。按回车恢复。
控制台 `/quit` 退出，`/stop` 软件急停并退出，`/disarm` 解除使能并退出。
说“结束对话”“停止聊天”“晚安塔斯”或“goodbye TARS”，回答后退出。
Ctrl+C 仍可停止。播放时麦克风关闭，不能依靠语音在播放中打断。

保持已验收的声音方案：模型 1.2.6.1、音色 S_vXjewQyk2、原始响度、
完成整句转换后播放、4 个 512 字节 PCM 包并行等待 ACK、板端音量 20%。
超过八秒的回复会分段，段间可能有停顿。缓冲最大 30 秒。
屏幕通过现有协议显示 LISTENING/THINKING/SPEAKING/IDLE 和中英文对话文字；
屏幕长文字仍受既有 300 字节限制，不代表本地记录只有 300 字节。

## 跨次记忆

默认 SQLite：`data/tars-voice.sqlite3`（含 WAL/SHM 文件，已忽略 Git）。
保存带日期的用户识别文字和确认播放的回答，不录制麦克风音频。
常见密钥表达会脱敏，每条文字上限 8000 字符，不宣称能检测所有秘密。

“记住：我喜欢……”会额外保存明确事实；“忘记：某个关键词”按文字匹配删除
相关本地记录，随后建立新的云会话上下文，避免继续引用旧会话里的已删信息。
这是关键词删除，不是通用语义遗忘或云服务全量数据删除。

启动会加载近期记录和事实，旧话题可通过 memory_lookup 工具检索完整本地历史。
每次提供给模型的历史最多 5000 字符。历史只是数据，不能直接驱动动作。
这一版没有额外模型摘要服务，不额外调用 LLM 做每日摘要。

本地查看、删除和备份：

```powershell
.\.venv\Scripts\python.exe -m tars_companion.voice_memory --recent
.\.venv\Scripts\python.exe -m tars_companion.voice_memory --forget "关键词"
.\.venv\Scripts\python.exe -m tars_companion.voice_memory --export "memory-backup.json"
```

命令行删除后需要重启正在运行的日常会话。备份需同时妥善保存，不包含 API Key。

## 语音动作

豆包通过 robot_command 提议动作，Companion 只按**本轮真实 ASR 文字**做本地解析。
必须明确叫“TARS／塔斯／塔尔斯”，不从历史、引号、否定句或模型自造参数执行。
支持前进、左转、右转、停止和状态；“向左走／向右走”映射转向，不是横移。
同一条口述指令最多执行一次，重复工具调用不会重复动作。
结果反馈依据现有命令终态，只有成功回执才使用成功台词。

默认**运动未使能**，仍可验证识别和拒绝反馈。自然语言不能 Arm。
实机运动需要另行完成原项目的物理准备与显式确认，然后从本地启动：

```powershell
.\Start-Tars-Seeduplex.ps1 -Daily -FreeTokens CURRENT_FREE_TOKENS -AllowMotion -ArmConfirmation I_HAVE_LIFTED_TARS_AND_CAN_CUT_SERVO_POWER
```

保持原有步态、安全状态、租约和急停规则。断线后最多恢复一次，新控制会话强制
disarm，不恢复 Arm、不重放未完成语音和动作。实际走动尚未在新端到端模式验收。
